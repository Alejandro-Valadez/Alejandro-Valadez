I'm a sophomore at the **Illinois Mathematics and Science Academy**, working across aerospace engineering, quantum computing, and competition math. I build small tools that solve problems I actually have — most recently, an MCP server that lets Claude read my Canvas coursework instead of me digging through it myself.

**The through-line:** find the tedious part, then build the smallest thing that removes it.
